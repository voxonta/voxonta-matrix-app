# Voxonta для Matrix 0.3.0

Первый самостоятельный установочный комплект Matrix с отдельным виджетом
транскрибации Element Call. Nextcloud и видеорекордер не требуются.

В комплекте: интеграция, widget, адаптер Synapse, собственный LiveKit capture,
Postgres и Compose. Исходники capture закреплены в deploy/capture.ref и включены
в архив. Получателю не нужно устанавливать другой продукт или клонировать
репозиторий capture. Образы собираются `docker compose up -d --build`.

- Явные start/pause/resume/finish, одна встреча при параллельных командах.
- Подтверждение состояния capture по session_id/revision, истекающий lease аудио.
- Устойчивые настройки, команды, саммари и расшифровки в Postgres.
- Публикация вручную или по отдельному согласию; по умолчанию выключена.
- Работа без бота; старый bot-mode сохранён для управляемой миграции.

Установка: README внутри архива; подробности — integration/docs/widget.md.
Публичный интеграционный образ: ghcr.io/voxonta/voxonta-matrix-app:0.3.0.
Для полной установки использовать архив, а не только этот образ.

Сборка и тесты проверены локально и в CI, включая реальный Synapse 1.163.2,
LiveKit и Postgres. Боевая приёмка внутри Element Web/Desktop ещё не завершена:
сначала тестовая личная и групповая комнаты, затем выбранные рабочие комнаты.
Адаптер использует закреплённые API Synapse 1.163.2; при другой версии сначала
проверить совместимость. Произвольные widgets Element X не поддерживаются.
Зашифрованные звонки этим захватом не поддерживаются.

Ни установка, ни публикация релиза автоматически не перезапускают Synapse,
существующий capture или другие сервисы. Обновление проводить вне звонков,
с резервной копией БД и прежних конфигураций/образов; не удалять прежний архив.
