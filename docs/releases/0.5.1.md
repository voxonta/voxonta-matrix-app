# Voxonta для Matrix 0.5.1

Voxonta определяет кандидатов на захват по сохранённым событиям MatrixRTC.
Полное состояние запрашивается для комнат с признаками звонка и уже отслеживаемых
сессий. Это сокращает число запросов к Synapse при большом числе пустых комнат.

Разрешение на захват обновляется отдельно для каждой комнаты. Если состояние
одной комнаты недоступно, захваты в остальных продолжаются. Когда состояние
снова доступно и звонок ещё идёт, захват возобновляется в той же сессии.

Поле `widget_capture_unconfirmed` в `/healthz` показывает число автоматических
захватов без свежего подтверждения спустя 15 секунд. Для оповещений добавьте
проверку этого поля в мониторинг.

Для обновления с 0.5.0 сначала установите адаптер из комплекта и перезапустите
Synapse в окно без звонков, затем обновите интеграцию. Перед работами сохраните
резервные копии баз Synapse и Voxonta. Используйте действующие `.env`, имя
Compose-проекта и том PostgreSQL.

Проверено на Synapse 1.163.2. Пройдены 188 тестов Python и сквозной сценарий
автостарта и публикации. На стенде с LiveKit и синтетическим микрофоном проверены
5, 10 и 20 одновременных звонков и задержка ответа одной комнаты на 6,5 секунды.
Остальные захваты продолжились, в каждой комнате опубликована одна пара тестовых
файлов. Распознавание в этом прогоне заменялось тестовыми результатами.
