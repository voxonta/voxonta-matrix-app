# Voxonta для Matrix 0.5.0

Самостоятельный виджет публикует саммари и расшифровку двумя файловыми
сообщениями в основной ленте комнаты: сначала саммари, затем расшифровку.
Нет отдельного объявления и треда. Оба вложения доступны в разделе файлов
Element. Имена содержат дату начала встречи (UTC), название комнаты и тип
материала. Если готов только один материал, публикуется только он.

Файлы сохраняются в медиахранилище Synapse; доступ к архиву через виджет
сохраняется. Повтор после частичной доставки не дублирует уже отправленный
файл. Неправильные данные всей пары отклоняются до начала отправки.

Обновление с 0.4.x требует новой интеграции И нового адаптера Synapse.
Сначала установить адаптер из комплекта и перезапустить Synapse в окно без
звонков, затем обновить интеграцию. Старый запрос публикации ссылок оставлен
совместимым для обновления. Сохранить конфигурацию, имя Compose-проекта и
volume PostgreSQL; не использовать down -v. Сделать резервную копию БД
интеграции и Synapse перед обновлением.

Автонастройки и разрешения комнат сохраняются. Уже опубликованные сообщения
со ссылками не заменяются и не дублируются автоматически. OpenID single-flight
из 0.4.1 включён; локальный патч повторно не накладывать.

Проверено на Synapse 1.163.2: публикация двух m.file без треда, скачивание с
точным совпадением содержимого, повтор и частичная доставка. Проверена выдача
файлов из PostgreSQL после рестарта. 185 Python-тестов прошли, один пропущен;
восемь JS-тестов прошли, линтер чистый.

SaaS, Nextcloud, capture и LiveKit не изменены и обновления не требуют.
Legacy-режим с ботом не менялся. Выпуск автоматически серверы не обновляет.
