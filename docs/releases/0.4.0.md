# Voxonta для Matrix 0.4.0

Самостоятельный Matrix-комплект с комнатными автонастройками.
Nextcloud, SaaS и отдельный capture обновлять не требуется: всё необходимое
для интеграции/захвата находится в одном установочном архиве.

## Новое

- Администратор комнаты может включать авторасшифровку новых звонков и
  автопубликацию результатов двумя отдельными флажками в панели.
- Преднастройки установки: WIDGET_AUTO_TRANSCRIBE_DEFAULT=true и
  WIDGET_AUTO_PUBLISH_DEFAULT=true. Обе изначально false, сохранённые настройки
  комнаты не перезаписываются.
- Новый адаптер Synapse обнаруживает комнаты с widget без открытой панели;
  предусмотрен backfill_rooms для ранее установленных виджетов.
- Установка widget в новые чаты по auto_install остаётся отдельной опцией.
- Ручная пауза/завершение не перезапускают тот же звонок, реконнект и рестарт
  сохраняют сессию. Включение политики во время звонка ждёт следующего экземпляра.

## Обновление

Обновить весь Matrix-комплект **и файл адаптера Synapse**, не только .env или UI.
Адаптер проверен на Synapse 1.163.2. Перезапуск Synapse проводить вне звонков.
Он создаёт собственный реестр voxonta_widget_rooms — включить в резервное
копирование. Для старых widget-комнат добавить явный backfill_rooms.

Полная установка описана в README внутри архива и integration/docs/widget.md.
Резервировать существующую БД и конфигурации, не удалять архивы и volumes.
Не запускать старый и новый capture на одну комнату одновременно.
Сначала проверить личную и групповую комнаты в настоящем Element Web/Desktop,
включая паузу, завершение и результат при закрытой панели.

CI и локальные проверки включают Postgres, настоящий Synapse и автоматический
сценарий с синтетическими файлами gateway. Приёмка живого аудио на боевой
установке остаётся задачей эксплуатации. Element X и зашифрованные звонки
этой интеграцией не поддерживаются. Публикация релиза серверы не перезапускает.
